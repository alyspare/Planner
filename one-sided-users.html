One-Sided Users

Accounts you follow that don’t follow you back. Import your Instagram download, then work down the list: open a profile, unfollow, and mark it here.

Sync across devices

Save to GitHub

Keeps your last import and your marks in a data file in one of your GitHub repos, so your phone, iPad and computer share one list.


Open file on GitHub ↗
How to set this up (about 5 minutes)
  1. On GitHub, create a new private repository to hold the data, for example blyssful-data. It can be empty.
  2. Open github.com/settings/personal-access-tokens/new (Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token).
  3. Name it One-Sided Users and pick an expiration. Under Repository access, choose Only select repositories and pick your data repo.
  4. Under Permissions › Repository permissions, set Contents to Read and write. Generate the token and copy it.
  5. Enter your username, the repo name and the token here, then tap Connect. Do the same once on each device.

The token stays in this browser on this device and is only ever sent to GitHub. Give it access to the data repo only. Each batch of changes is saved as a small commit to that repo, and the page checks for changes from your other devices whenever you come back to it.

Step 1

Import your Instagram files

Your files are read on this device. Only the one-sided list and your marks are saved.

Drop your Instagram download here

The whole ZIP (best: it carries the export date), or following.json and followers_1.json from inside it. Add followers_2.json and recently_unfollowed_profiles.json too if you have them.

How to get these files from Instagram
  1. In Instagram, open Settings, then Accounts Center (it may say Meta Account), then Your information and permissions.
  2. Tap Export your information (older versions say Download your information), then Create export.
  3. Pick your Instagram profile, then Export to device.
  4. Under Customize information, choose just Followers and following. Set Date range to All time and Format to JSON, then start the export.
  5. When Instagram emails you that it’s ready, download the ZIP and drop it here. Or unzip it and choose the files in connections › followers_and_following.

Instagram’s download is a snapshot from the day you request it. Your first import records every follower and the date they followed you. Each import after that compares against the last one, and anyone missing is recorded as having unfollowed you between those two export dates. Importing every week or two keeps those windows short.
